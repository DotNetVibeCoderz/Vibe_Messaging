BenchmarkDotNet output for SocketSignal - codec and dispatch micro-benchmarks.
Gravicode Studios, led by Kang Fadhil.

Reproduce with:
    dotnet run -c Release --project src/SocketSignal.Benchmarks -- micro

Only the summary tables are kept here; the full run log (build output, jitting, pilot and
workload iterations) is ~2,300 lines and is regenerated by the command above.

NOTE on the allocation columns: the MemoryDiagnoser did not emit for every group in this run,
so the allocation figures quoted in docs/performance.md come from the dedicated measurement
(`-- alloc`), which uses GC.GetTotalAllocatedBytes over 200,000 operations. Trust the Mean and
Ratio columns here; trust `-- alloc` for bytes.
